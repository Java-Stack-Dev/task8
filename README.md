# Task 8: Simple Sales Dashboard – Data Analyst Internship

## Objective
To create a clean and interactive sales dashboard using Tableau that highlights sales performance by product category, region, and monthly trends.

## Dataset Used
**Sample - Superstore.csv**  
This dataset contains retail sales information, including:
- Order Date
- Sales
- Profit
- Region
- Category

##  Tools Used
- Tableau Public (for dashboard creation)
- Microsoft Excel (for initial inspection)

##  Steps Followed
1. Imported the dataset into Tableau.
2. Converted the `Order Date` to **Month-Year** format.
3. Created 3 main visualizations:
   - **Line Chart:** Sales trend over time.
   - **Bar Chart:** Sales by Region.
   - **Donut Chart:** Sales by Category.
4. Added a **filter (slicer)** to view data by different **Regions**.
5. Designed a clean dashboard layout using colors to highlight top-performing areas.

##  Dashboard Overview
The dashboard includes:
- **Interactive filter by Region**
- **Sales trend analysis across months**
- **Comparison of regional and category-wise performance**


##  Key Insights
1. The **West Region** had the highest total sales overall.
2. **Technology** category performed best in terms of sales.
3. **December** showed the highest spike in monthly sales.
4. **South Region** showed consistent growth over the months.
